# 新工具使用示例

## 📋 概述

本文档提供新创建的工具类的使用示例，帮助开发者快速上手。

## 🔧 工具类说明

### 1. 统一请求工具 (utils/request.js)

封装了 `wx.request`，提供统一的请求接口和错误处理。

#### 基本使用

```javascript
const request = require('../../utils/request');

// GET 请求
const res = await request.get('/userinfo', { id: 'userId123' });
if (res.success) {
  console.log('用户信息:', res.data);
}

// POST 请求
const res = await request.post('/addUser', {
  userName: '用户名',
  userId: 'userId123'
});
if (res.success) {
  console.log('添加成功');
}

// 文件上传
const res = await request.upload({
  url: '/upload',
  filePath: 'tempFilePath',
  formData: { type: 'avatar' }
});
if (res.success) {
  console.log('上传成功:', res.data);
}
```

#### 高级配置

```javascript
// 不显示加载提示
const res = await request.get('/userinfo', { id: 'userId123' }, {
  showLoading: false
});

// 不显示错误提示（自定义处理）
const res = await request.post('/api', data, {
  showError: false
});
if (!res.success) {
  // 自定义错误处理
  console.error('请求失败:', res.message);
}
```

### 3. 认证服务 (utils/auth.js)

统一管理用户登录和认证相关逻辑。

#### 检查登录状态

```javascript
const authService = require('../../utils/auth');

// 在页面加载时检查登录状态
async onLoad() {
  const userInfo = await authService.checkLogin();
  if (userInfo) {
    this.setData({ userInfo });
  } else {
    // 未登录，引导用户登录
    this.showLoginModal();
  }
}
```

#### 微信登录

```javascript
const authService = require('../../utils/auth');

// 用户点击登录按钮
async handleLogin() {
  try {
    // 1. 获取用户授权
    const userProfile = await wx.getUserProfile({
      desc: '用于完善用户资料'
    });
    
    // 2. 微信登录
    const loginRes = await wx.login();
    
    // 3. 获取 OpenID
    const openIdRes = await API.user.getOpenId(loginRes.code);
    if (!openIdRes.success) {
      throw new Error('获取 OpenID 失败');
    }
    
    // 4. 创建或获取用户信息
    let userInfo = await authService.getUserInfo(openIdRes.data);
    if (!userInfo) {
      // 创建新用户
      userInfo = await authService.createUser(
        openIdRes.data,
        userProfile.userInfo.nickName
      );
    }
    
    // 5. 保存用户信息
    this.setData({ userInfo });
    getApp().globalData.userInfo = userInfo;
    
    wx.showToast({ title: '登录成功' });
  } catch (error) {
    wx.showToast({
      title: error.message || '登录失败',
      icon: 'none'
    });
  }
}
```

### 4. 错误处理工具 (utils/errorHandler.js)

统一处理各种错误情况。

#### 基本使用

```javascript
const errorHandler = require('../../utils/errorHandler');

try {
  // 一些可能出错的操作
  await someAsyncOperation();
} catch (error) {
  // 统一错误处理
  errorHandler.handleApiError(error);
}
```

#### 确认对话框

## 📝 迁移指南

### 从旧代码迁移到新工具

#### 旧代码示例

```javascript
// 旧代码
wx.request({
  url: app.host + '/userinfo',
  data: { id: userId },
  success: res => {
    if (res.data.code === 200) {
      this.setData({ userInfo: res.data.data });
    } else {
      wx.showToast({
        title: res.data.message,
        icon: 'none'
      });
    }
  },
  fail: err => {
    wx.showToast({
      title: err.errMsg,
      icon: 'none'
    });
  }
});
```

#### 新代码示例

```javascript
// 新代码
const API = require('../../services/api');

const res = await API.user.getUserInfo(userId);
if (res.success) {
  this.setData({ userInfo: res.data[0] });
}
// 错误处理已在 request 中统一处理
```

### 迁移步骤

1. **引入 API 服务**
   ```javascript
   const API = require('../../services/api');
   ```

2. **替换 wx.request 调用**
   - 查找所有 `wx.request` 调用
   - 替换为对应的 API 方法

3. **简化错误处理**
   - 移除重复的错误处理代码
   - 使用统一的错误处理

4. **测试验证**
   - 测试所有修改的接口
   - 确保功能正常

## 🎯 最佳实践

### 1. 统一使用 API 服务层

✅ **推荐**
```javascript
const API = require('../../services/api');

❌ **不推荐**

const res = await API.user.getUserInfo(userId);
if (res.success) {

```

## 📚 完整示例

### 页面完整示例

```javascript
// pages/myinfo/myinfo.js
const API = require('../../services/api');
const authService = require('../../utils/auth');

Page({
  data: {
    userInfo: null,
    playlists: []
  },

  async onLoad() {
    // 检查登录状态
    const userInfo = await authService.checkLogin();
    if (userInfo) {
      this.setData({ userInfo });
      await this.loadPlaylists();
    }
  },

  // 加载歌单列表
  async loadPlaylists() {
    const userId = this.data.userInfo?.userId;
    if (!userId) return;

    const res = await API.playlist.getPlaylistList(userId);
    if (res.success) {
      this.setData({ playlists: res.data });
    }
  },

  // 创建歌单
  async createPlaylist(name, imagePath) {
    // 先上传图片
    const uploadRes = await API.upload.uploadFile(imagePath);
    if (!uploadRes.success) {
      return;
    }

    // 创建歌单
    const res = await API.playlist.createPlaylist({
      userid: this.data.userInfo.userId,
      name: name,
      img: uploadRes.data
    });

    if (res.success) {
      wx.showToast({ title: '创建成功' });
      await this.loadPlaylists(); // 刷新列表
    }
  }
});
```

## ⚠️ 注意事项

1. **异步处理**：所有 API 调用都是异步的，需要使用 `async/await` 或 `.then()`

2. **错误处理**：虽然错误已统一处理，但建议检查 `res.success` 来判断是否成功

3. **兼容性**：新工具完全兼容旧代码，可以逐步迁移

4. **全局数据**：用户信息同时保存在 `app.globalData` 和 `app.data` 中，保持兼容
