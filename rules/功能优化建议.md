# wx-music 功能优化建议

## 📋 概述

本文档基于对 `wx-music` 项目的功能分析，结合 `wx_music_serve` 后端服务的功能特性，提出功能层面的优化建议。

## 🔍 功能分析

### 当前已实现的功能

1. ✅ 用户登录和注册
2. ✅ 歌曲搜索和播放
3. ✅ 歌单管理（创建、编辑、删除）
4. ✅ 播放列表管理
5. ✅ 歌词显示
6. ✅ 播放模式切换（顺序、循环、随机）

### 后端已支持但前端未充分利用的功能

根据 `wx_music_serve` 的接口分析，后端已实现以下功能，但前端可以更好地利用：

1. ✅ 用户信息管理（头像上传、信息编辑）
2. ✅ 歌单批量操作
3. ✅ 歌曲批量查询
4. ✅ 推荐歌单
5. ✅ 歌手和专辑信息

## 🚀 功能优化建议

### 1. 用户体验优化

#### 1.1 登录流程优化

**当前问题**：
- 登录逻辑复杂，嵌套回调多
- 错误处理不友好
- 缺少登录状态管理

**优化建议**：

```javascript
// utils/auth.js
class AuthService {
  // 检查登录状态
  async checkLogin() {
    try {
      const openId = await wx.getStorage({ key: 'openId', encrypt: true });
      if (openId.data) {
        return await this.getUserInfo(openId.data);
      }
      return null;
    } catch {
      return null;
    }
  }

  // 微信登录
  async wxLogin() {
    try {
      // 1. 获取 code
      const loginRes = await wx.login();
      
      // 2. 获取 OpenID
      const openIdRes = await API.user.getOpenId(loginRes.code);
      if (!openIdRes.success) {
        throw new Error('获取 OpenID 失败');
      }
      
      const openId = openIdRes.data;
      await wx.setStorage({
        key: 'openId',
        data: openId,
        encrypt: true
      });

      // 3. 获取用户信息
      const userRes = await API.user.getUserInfo(openId);
      if (userRes.success && userRes.data.length > 0) {
        return userRes.data[0];
      }

      // 4. 创建新用户
      const userInfo = await wx.getUserProfile({
        desc: '用于完善用户资料'
      });
      
      const addRes = await API.user.addUser({
        userName: userInfo.userInfo.nickName,
        userId: openId
      });
      
      if (addRes.success) {
        const newUserRes = await API.user.getUserInfo(openId);
        return newUserRes.data[0];
      }
      
      throw new Error('创建用户失败');
    } catch (error) {
      console.error('登录失败:', error);
      wx.showToast({
        title: '登录失败，请重试',
        icon: 'none'
      });
      throw error;
    }
  }

  // 获取用户信息
  async getUserInfo(userId) {
    const res = await API.user.getUserInfo(userId);
    if (res.success && res.data.length > 0) {
      const userInfo = res.data[0];
      if (userInfo.headimg) {
        userInfo.avatarUrl = `${getApp().host}/${userInfo.headimg}`;
      }
      return userInfo;
    }
    return null;
  }
}

module.exports = new AuthService();
```

**使用示例**：

```javascript
// app.js
const authService = require('./utils/auth');

App({
  async onLaunch() {
    // 检查登录状态
    const userInfo = await authService.checkLogin();
    if (userInfo) {
      this.globalData.userInfo = userInfo;
    } else {
      // 自动登录
      try {
        this.globalData.userInfo = await authService.wxLogin();
      } catch (error) {
        // 登录失败，可以引导用户手动登录
      }
    }
  }
});
```

#### 1.2 播放体验优化

**优化建议**：

1. **播放历史记录**
   ```javascript
   // utils/playHistory.js
   class PlayHistory {
     async add(song) {
       const history = await this.getHistory();
       // 移除重复项
       const filtered = history.filter(item => item.id !== song.id);
       // 添加到开头
       filtered.unshift({
         ...song,
         playTime: Date.now()
       });
       // 最多保存 100 条
       const limited = filtered.slice(0, 100);
       await wx.setStorage({
         key: 'playHistory',
         data: limited
       });
     }

     async getHistory() {
       try {
         const res = await wx.getStorage({ key: 'playHistory' });
         return res.data || [];
       } catch {
         return [];
       }
     }

     async clear() {
       await wx.removeStorage({ key: 'playHistory' });
     }
   }

   module.exports = new PlayHistory();
   ```

2. **播放统计**

   // utils/searchHistory.js
   class SearchHistory {
     async add(keyword) {
       if (!keyword || !keyword.trim()) return;
       
       const history = await this.getHistory();

         return res.data || [];
       } catch {

#### 3.2 数据缓存

**优化建议**：

1. **API 响应缓存**
   ```javascript
   // utils/cache.js
   class Cache {
     async get(key) {
       try {
         const res = await wx.getStorage({ key });
         if (res.data.expire > Date.now()) {
           return res.data.value;
         }
         await wx.removeStorage({ key });
         return null;
       } catch {
         return null;
       }
     }

     async set(key, value, expire = 3600000) { // 默认 1 小时
       await wx.setStorage({
         key,
         data: {
           value,
           expire: Date.now() + expire
         }
       });
     }
   }

   module.exports = new Cache();
   ```

### 4. 错误处理和容错

#### 4.1 网络错误处理

**优化建议**：

1. **重试机制**
   ```javascript
   async function requestWithRetry(requestFn, maxRetries = 3) {
     for (let i = 0; i < maxRetries; i++) {
       try {
         return await requestFn();
       } catch (error) {
         if (i === maxRetries - 1) {
           throw error;
         }
         await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)));
       }
     }
   }
   ```

2. **离线检测**
   ```javascript
   wx.onNetworkStatusChange((res) => {
     if (!res.isConnected) {
       wx.showToast({
         title: '网络连接已断开',
         icon: 'none'
       });
     }
   });
   ```
